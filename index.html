How the tracer works

The solid red line is built from frames where BallTrace genuinely detects the ball. If the pixels disappear, it searches ahead for reacquisition, then uses a dashed gold line for a rough flight continuation based on the measured early path.

On iPhone: open in Safari, tap Share, then Add to Home Screen.
